# 🎣 台灣釣魚郵件偵測器

針對**台灣在地中文釣魚信**設計的偵測工具，結合「規則檢查」與「本機 LLM」兩層判斷，並與市售工具（Bitdefender Scamio、Gmail 內建過濾）比較。

> 國立宜蘭大學 資訊安全導論 期末專題（2026 秋）

## 為什麼做這個

- 生成式 AI 讓釣魚信變得零錯字、語氣自然，傳統靠「錯字、怪語氣」辨識的方法失效
- 市售防詐工具多以英文為主，台灣常見手法（解除分期、引導加 LINE、冒充 `.gov.tw`、繁簡混用）不一定抓得到
- 釣魚信裡常帶有收件人的真實姓名與手機，代表個資外洩後的**精準釣魚**越來越常見

## 系統架構

```
信件（貼上文字或上傳 .eml）
   │
   ├─▶ 第 1 層：規則檢查 rules.py
   │     寄件者／網址／話術／附件，共十多條規則，輸出 0–100 分＋理由
   │
   ├─▶ 第 2 層：LLM 判斷 llm.py
   │     本機 Ollama（Qwen），輸出釣魚機率＋理由＋可疑片段
   │
   └─▶ 綜合分數 = 規則 × 0.4 ＋ LLM × 0.6
         ≥ 45 釣魚 ／ 25–44 可疑 ／ < 25 正常
```

### 第 1 層規則（節錄）

| 類別 | 規則 |
|---|---|
| 寄件者 | 免費信箱冒充商家、`.jp` 網域寄台灣中文信、仿冒官方網域、自稱政府但非 `.gov.tw` |
| 網址 | IP 網址、仿冒網域（`sh0pee`、`niu-edu-tw`、`line-xxx`）、高風險 TLD（`.icu` 等）、直接下載壓縮檔 |
| 內容 | 急迫／恐嚇話術、金錢關鍵字、要求登入驗證、**引導加 LINE**、**×12 分期**、**繁體夾雜簡體** |
| 附件 | 壓縮檔、可執行檔、含巨集的 Office 檔 |
| 白名單 | 寄件者與所有連結都是官方網域時降分 |

### 第 2 層設計重點

- `temperature = 0`：同一封信每次結果一致，實驗可重現
- **防 Prompt Injection**：信件內容放在 `<email>` 標籤中，並要求模型把它當資料而非指令；信裡若要求模型改變判斷，視為可疑特徵

## 安裝與執行

```bash
# 1. 安裝 Ollama（https://ollama.com）並下載模型
ollama pull qwen2.5:7b

# 2. 安裝 Python 套件
pip install -r requirements.txt

# 3. 啟動介面
python3 app.py          # 開啟 http://127.0.0.1:7860

# 只跑規則層的測試
python3 run_test.py
```

## 資料集

`data.json` 共 15 封（持續增加中），分為：

- **AI 生成範例**：用虛構的 `.test` 網域撰寫
- **外部整理劇本**：未經查證的模擬案例
- **真實收到**：作者信箱中的真實釣魚信與被誤判的正常信

所有網址皆已**去武裝化**（`hxxps://evil[.]com`），收件人姓名、手機、信箱都已替換為 `【姓名】` 等代號。

## 目前結果與限制

- 規則層在 `data.json` 上 15/15 判斷正確，**但規則是參考這批資料設計的，有過擬合風險**；正式評估會使用另外蒐集、未參與設計的測試信
- 規則名單（官方網域、關鍵字）需要人工維護
- LLM 判斷速度受本機硬體影響
